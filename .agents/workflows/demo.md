---
description: Preparar y levantar la demo desde cero
---
1. Ejecuta `npm install`.
2. Ejecuta `npm run seed` para recrear la base con los 100 deudores y a Gengis Guerrero.
3. Ejecuta `npm run dev` y abre http://localhost:3000.
4. Entra como cliente (`/cliente`) y como gestor (`/banco`, usuario `gestor`, clave `caja2026`) en dos pestañas.
5. Sigue el guion de 3 minutos del README.
